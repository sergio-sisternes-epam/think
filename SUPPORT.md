# Support

## How to get help

- **Bug reports:** [Open an issue](https://github.com/sergio-sisternes-epam/think/issues/new?template=bug_report.md) using the bug report template.
- **Feature requests:** [Open an issue](https://github.com/sergio-sisternes-epam/think/issues/new?template=feature_request.md) using the feature request template.

## Before opening an issue

1. Search [existing issues](https://github.com/sergio-sisternes-epam/think/issues) to check if it has already been reported.
2. Include your APM CLI version (`apm --version`) and OS.
3. Provide minimal reproduction steps.

## Scope

This repository is maintained on a best-effort basis. For urgent needs, contact the maintainers listed in [AUTHORS](./AUTHORS).
