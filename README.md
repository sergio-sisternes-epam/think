# think

> Private APM marketplace for Grok-native think primitives: challenge, grill, and ramble.

[![Marketplace](https://github.com/sergio-sisternes-epam/think/actions/workflows/marketplace.yml/badge.svg)](https://github.com/sergio-sisternes-epam/think/actions/workflows/marketplace.yml)
[![PR Validate](https://github.com/sergio-sisternes-epam/think/actions/workflows/pr-validate.yml/badge.svg)](https://github.com/sergio-sisternes-epam/think/actions/workflows/pr-validate.yml)

This marketplace ships three packages under `packages/`. It does **not** include an Atlas store.

## Packages

| Package | Description | Install |
|---------|-------------|---------|
| `think-challenge` | Challenge ideas with search-grounded counter-arguments and critic perspectives. | `apm install think-challenge@think` |
| `think-grill` | Socratic questioning to refine ideas, clarify assumptions, and strengthen content. | `apm install think-grill@think` |
| `think-ramble` | Capture free-form thoughts and half-formed ideas; persist when a store is available. | `apm install think-ramble@think` |

## Quick start

```bash
apm marketplace add sergio-sisternes-epam/think
apm install think-challenge@think
```

Each package is a single-skill unit (`apm.yml` + `SKILL.md`). Conversation-only use works when no durable store is present.

## Layout

```
apm.yml
.claude-plugin/marketplace.json   # generated by `apm pack` — do not edit
packages/
  think-challenge/
  think-grill/
  think-ramble/
```

Scoped tags: `{name}/v{version}` (for example `think-grill/v1.0.0`).
